# Security policy

Do not report vulnerabilities through a public issue. Contact `nagaraj.rbhagwat@expleogroup.com` with reproduction steps and impact.

The MVP binds to `127.0.0.1` by default and has no authentication. Before shared or production-like deployment, add TLS, identity-based access control, request rate limits, audit logging, network segmentation, encrypted durable storage, retention controls and independent security review.

Never submit real fleet credentials, secrets, personal data, or customer VINs to the public repository.
