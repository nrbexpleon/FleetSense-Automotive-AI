# Contributing

1. Create a focused branch and issue.
2. Preserve explicit units, deterministic behaviour and explainable scoring.
3. Add tests for behaviour and failure cases.
4. Run `python -m unittest discover -s tests -v`.
5. Do not claim proven causation, guaranteed RUL, or safety certification.
6. Do not add telemetry, credentials, customer identifiers or confidential data.

By contributing, you confirm you have the right to submit the contribution under the repository's proprietary licence.
